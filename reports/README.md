# Report artefacts

Keep report-ready figures and tables here. Automatically generated intermediate files belong in the `generated/` subdirectories and remain ignored until a result is deliberately selected for the report.

Every final figure or table should be traceable to a notebook, script, configuration and frozen data split.

The `eda/` directories contain the selected exploratory-analysis evidence generated by `scripts/run_eda.py` and presented in `notebooks/01_exploratory_data_analysis.ipynb`.

The `annotation_conversion/` directories contain the compact verification summary and visual overlay produced during Pascal VOC to YOLO conversion. The full generated dataset remains outside Git.

The `preprocessing/` directories contain intensity histograms, technique comparisons, visibility metrics and the evidence supporting the preprocessing decision.
